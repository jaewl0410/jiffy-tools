Temperature Converter

Convert temperature units instantly. Choose two units, enter a value, and see the result as you type.

How to use it

Choose any two temperature units. The result updates as you type, and Swap reverses the direction.

Temperature conversion includes an offset. Values below absolute zero are not valid.

Examples

  • 0 °C = 32 °F
  • 100 °C = 212 °F
