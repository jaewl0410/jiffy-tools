Data Storage Converter

Convert data storage units instantly. Choose two units, enter a value, and see the result as you type.

How to use it

Choose any two data storage units. The result updates as you type, and Swap reverses the direction.

Decimal units use SI: 1 KB = 1,000 B, 1 MB = 1,000,000 B. Binary units use IEC: 1 KiB = 1,024 B, 1 MiB = 1,048,576 B.

Examples

  • 1 MB = 0.001 GB
  • 1,000 MB = 1 GB
